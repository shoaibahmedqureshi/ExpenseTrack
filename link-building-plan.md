# Link-Building Plan — Outlay & Stitchify

A backlink is only worth pursuing if a real person would click it. Everything below is aimed at
genuine placements, not link farms or paid schemes — the kind of links that survive Google's spam
updates instead of triggering a manual action.

## 1. Directory submissions (do these first — cheapest, fastest)

Free, legitimate directories that list apps/tools and allow a backlink. Submit both apps to each;
submit the calculator tools separately to the tool-specific ones.

| Directory | What to submit | Notes |
|---|---|---|
| [Product Hunt](https://www.producthunt.com) | Outlay, Stitchify (as "Launches") | Time the launch — Tuesday–Thursday, early US morning, gets most visibility |
| [AlternativeTo](https://alternativeto.net) | Both apps | List as alternative to Mint/YNAB (Outlay) and Google Photos collage tools (Stitchify) |
| [SaaSHub](https://saashub.com) | Both apps | Free listing, decent domain authority |
| [BetaList](https://betalist.com) | Whichever app is earliest-stage | Best before/at a version-1 launch, less useful post-launch |
| [Free-tools directories] (e.g. "TheresAnAIForThat"-style calculator/tool roundups) | The 6 Outlay calculators + 4 Stitchify image tools individually | Search "submit your free tool" + the tool's category |
| [G2](https://www.g2.com) / [Capterra](https://www.capterra.com) | Outlay (as expense-tracking software) | Takes longer to get listed/verified but carries real weight |
| Slant, StackShare | Outlay | Community-driven "best X for Y" comparison sites |

Each submission needs a short blurb — I can draft one per directory on request once you're ready
to submit (tone/length varies by site).

## 2. Outreach targets — personal finance content creators

The free calculators are the pitch: "here's a genuinely useful free tool for your audience,"
not "please link to my app." Target creators covering personal finance in the languages you've
already localized for.

| Market | Where to look | Angle |
|---|---|---|
| Pakistan (Urdu/English) | YouTube search "budgeting Pakistan", "salary planning Pakistan"; Twitter/X finance accounts | Budget planner + 50/30/20 calculator, PKR-denominated |
| India (Hindi/English) | YouTube "personal finance India", finance Instagram/YouTube creators | Same tools, INR-denominated, mention SIP/investment angle for compound interest calculator |
| Indonesia | YouTube "keuangan pribadi", finance blogs | IDR-denominated tools |
| Vietnam | YouTube "tài chính cá nhân" | VND-denominated tools |
| Philippines | YouTube "personal finance Philippines", finance Facebook groups | PHP-denominated tools |
| Bangladesh | Finance Facebook pages/groups (less YouTube density) | BDT-denominated tools |
| MENA (Arabic) | YouTube/Instagram finance creators in Gulf states | AED/SAR-denominated tools, higher CPC market generally |

### Outreach email template (finance bloggers/YouTubers)

```
Subject: A free [budget/compound-interest/currency] calculator for your [Country] audience

Hi [Name],

I've been following your [channel/blog] — the video on [specific recent topic] was genuinely
useful.

I built a free, no-signup [tool name] calculator (link) aimed at [Country] readers —
it's in [Language] and defaults to [Currency]. No account wall, nothing to download, just a
tool people can actually use.

If it's useful for your audience, feel free to link it in a relevant video description or post.
No ask beyond that — just thought it might save your viewers some time.

Thanks for the content you put out,
[Your name]
```

Keep it that short. Don't ask for a link explicitly — offering something useful and mentioning
it's shareable is the entire pitch; asking directly reads as link-begging and lowers response rates.

## 3. The influencer program (already-built asset)

You already have an influencer revenue-share system live in the app. Add one line to the
onboarding/brief you give new influencer partners: point them at the free calculator relevant to
their content (budget planner for a "how I budget" video, compound interest for an investing
video) as a natural companion link alongside their referral code. This is a legitimate,
already-warm channel — no separate outreach needed, just make sure it's mentioned in whatever
brief/message goes to influencers.

## 4. What NOT to do

- No link directories that promise "500 backlinks for $X" — these are link farms, and Google's
  spam algorithms specifically target them. A manual action here would hurt both the tools and
  outlayapp.net/stitchifyapp.net's ability to rank at all.
- No mass Reddit/Quora posting — a genuinely helpful answer to a real question, with the tool
  linked where relevant, is fine; posting the same link across dozens of threads reads as spam
  and gets accounts banned.
- No reciprocal link exchanges ("link to me, I'll link to you") — Google explicitly flags these
  as a link scheme.
